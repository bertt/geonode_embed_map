Embed a GeoNode map in an external site

GeoNode maps and layers can be used in any static HTML page. These examples use the map Entidades_PVCV from the public GeoNode demo instance stable.demo.geonode.org. There are two approaches:

  • 1. iframe
    Embed the complete GeoNode map viewer with GeoNode's /maps/<ID>/embed URL. Simplest, and keeps the map's styling and layers exactly as configured in GeoNode.
  • 2. Custom map with MapLibre GL JS
    Build your own map and load the GeoNode layer via the WMS service of GeoServer. Clicking a feature shows its attributes using WMS GetFeatureInfo.

Instructions and source code: github.com/bertt/geonode_embed_map.
